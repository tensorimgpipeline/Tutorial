# TIPI Tutorial

This tutorial provides a step-by-step example, to convert a common script into a TIPI CLI project.

The process gives the user a feeling via the leveled approach how a huge script could be organized.

There are two options to work on the Tutorial.
Either you clone this tutorial and analyze the different steps:

```bash
git clone https://github.com/tensorimgpipeline/Tutorial.git
```

Or you create the levels from scratch by starting with the example code of `level_0`:

[level_0 example](https://raw.githubusercontent.com/tensorimgpipeline/Tutorial/refs/heads/main/level_0/train.py)
